首个安卓原生预览版，使用 Kotlin、Jetpack Compose 与 Material Design 3。

- 校园动态、搜索与排序、话题、表白墙粒子爱心、失物招领。
- 学号登录、注册、个人资料、头像、邮箱与密码管理。
- 发帖、拍照与附件上传、投票、评论与回复、赞踩、收藏、举报与反馈。
- 图片预览、原生音视频播放、系统分享、消息通知、深色模式与动态配色。
- 按账号权限开放内容审核、用户管理、公告、举报、反馈、回收站及平台设置。

下载 `.apk` 安装，支持 Android 8.0 及以上。`.aab` 供应用分发使用，不能直接安装。

安装包由本仓库 GitHub Actions 完成构建及专用密钥签名，附 SHA-256 校验和与签名验证结果。更新时请保持使用相同来源的签名版本。

说明：与网页版共用账号及数据。安全验证使用系统浏览器，完成后返回 App；校园墙界面均为原生组件。后台消息检查约每 15 分钟一次，实际时机受系统省电策略影响。设备自动测试验证接口契约、匿名数据与会话保护；真实账号的发帖、审核等线上写操作仍需试用验收，因此本次标为预览版。
