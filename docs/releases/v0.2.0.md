全新液态玻璃界面预览版。舍弃旧版 Material Design 界面，所有页面基于 [AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass) 重新设计。

- 底部标签栏、按钮、开关、标签、输入框、分段选择器、卡片和弹窗全部为液态玻璃：按压放大、跟随手指弹性形变，并带有高光与边缘折射。
- 底部标签栏的选中指示器是一块可拖动的玻璃透镜；卡片内的按钮会继续折射卡片玻璃；弹窗模糊整个页面。
- 新增：消息未读数角标、官方帖子标识、图片双指缩放与拖动、删除评论前确认。
- 设置页无需登录即可切换深浅色与系统动态配色，系统栏颜色跟随应用设置。
- 功能与接口保持不变：动态、话题、表白墙、失物招领、发帖投票、评论、收藏、举报反馈、消息通知及按权限开放的管理中心。

下载 `.apk` 安装，支持 Android 8.0 及以上。实时模糊需要 Android 12，透镜折射需要 Android 13；更低版本自动使用更不透明的玻璃底色，保证文字清晰。`.aab` 供应用分发使用，不能直接安装。

安装包由本仓库 GitHub Actions 完成构建及专用密钥签名，附 SHA-256 校验和与签名验证结果。可直接覆盖安装 v0.1.x。

说明：构建工具升级至 AGP 9.3、Kotlin 2.4、Compose 1.12。新界面尚需在不同厂商手机上试用验收，因此本次标为预览版。
